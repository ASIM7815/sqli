# QueryQuest - Render Deployment Guide

This guide will help you deploy the QueryQuest SQL injection challenge application to Render.

## Prerequisites

- A [Render](https://render.com) account (free tier works)
- A GitHub account
- Git installed locally

## Quick Deploy

### Option 1: Deploy from GitHub (Recommended)

1. **Push your code to GitHub:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit - QueryQuest CTF challenge"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/queryquest.git
   git push -u origin main
   ```

2. **Deploy on Render:**
   - Go to [Render Dashboard](https://dashboard.render.com/)
   - Click **"New +"** → **"Web Service"**
   - Connect your GitHub repository
   - Render will auto-detect the `render.yaml` file
   - Click **"Apply"** to create the service

3. **Configure Environment Variables (Optional):**
   - `SECRET_KEY` - Auto-generated by Render
   - `CTF_FLAG` - Update to your custom flag (default: `CTF{legacy_query_exposed_find_the_hidden_records}`)
   - `COOKIE_SECURE` - Set to `1` (already configured)

4. **Wait for deployment:**
   - The build process will install dependencies and initialize the database
   - Once complete, your app will be live at `https://queryquest-XXXX.onrender.com`

### Option 2: Manual Configuration

If you prefer not to use `render.yaml`:

1. **Create a new Web Service** on Render Dashboard
2. **Connect your repository**
3. **Configure the service:**
   - **Name:** queryquest
   - **Runtime:** Python 3
   - **Build Command:** `pip install -r requirements.txt && python init_db.py`
   - **Start Command:** `gunicorn --bind 0.0.0.0:$PORT --workers 2 --timeout 30 --access-logfile - --error-logfile - 'app:create_app()'`
4. **Add Environment Variables:**
   - `SECRET_KEY` → Generate a random value
   - `CTF_FLAG` → Your challenge flag
   - `COOKIE_SECURE` → `1`
   - `PYTHON_VERSION` → `3.11`
5. **Add Persistent Disk (Optional but recommended):**
   - Name: `queryquest-data`
   - Mount Path: `/opt/render/project/src/instance`
   - Size: 1 GB

## Troubleshooting

### Database Issues
If the database doesn't initialize:
- Check build logs in Render dashboard
- Ensure the persistent disk is mounted correctly
- The database auto-initializes on first run

### Environment Variables
- Render auto-generates `SECRET_KEY` if not set
- Update `CTF_FLAG` in the Render dashboard under "Environment"
- Changes require a manual redeploy

### Application Not Starting
Check the Render logs:
- Go to your service dashboard
- Click "Logs" tab
- Look for Python/Gunicorn errors

### Free Tier Limitations
- Render free tier services spin down after 15 minutes of inactivity
- First request after spindown may take 30-60 seconds
- Upgrade to paid plan for always-on service
